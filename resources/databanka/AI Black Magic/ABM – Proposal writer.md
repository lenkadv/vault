# Proposal writer

**Použij, až:** píšeš nabídku klientovi

Generates complete client proposals from a conversational scope discussion, producing a professional document with executive summary, problem statement, proposed solution, deliverables, pricing, timeline, and terms. Use when a user needs to send a proposal to a prospect, formalize a project scope, or respond to an RFP.
