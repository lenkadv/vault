# První AI agent s Claude Managed Agents

**Použij, až:** vysvětluješ začátečníkům rozdíl mezi chatbotem a agentem

**Zdroj:** https://aiblackmagic.com/free/agent/view (bezplatná ukázka z placené knihovny, mail AI Black Magic 24. 10. 2026; samotný text https://aiblackmagic.com/media/editor-content/1780385809646-ctnoeo5o3xs-first-ai-agent-claude-no-code.html)

**Co to je (Claude 261025):** návod pro začátečníky na Claude Managed Agents v konzoli platform.claude.com (vývojářská konzole, ne běžná aplikace Claude): předplacený kredit od 5 USD, šablony (Deep Researcher, Support Agent…), agent běží na serverech Anthropicu, platí se tokeny + 0,08 USD za hodinu běhu. Silné jsou dvě věci k vysvětlování: obraz **„chatbot = mozek ve sklenici, agent = mozek s rukama“** a čtyři stavební kameny jako vaření (agent = recept, prostředí = kuchyně, session = jedno jídlo, události = průběh). K tomu bezpečnostní zásada „dej agentovi jen nástroje, které potřebuje“.

**Pro nás:** Lenka agenty už používá přes Claude Code, Managed Agents nepotřebuje. Pro DigiStart se hodí jako výkladový materiál (analogie na setkání), ne jako nástroj pro účastnice: chce účet v konzoli, kartu a kredit navíc k Claude Pro.
