# webinar-build

**Použij, až:** Build a webinar end to end: the structure scaled to a length target, belief-chain chapter design, segment scripts in spoken register with delivery cues, a…

**Spuštění:** /webinar-build (automaticky v sezení otevřeném v GrowOS; z vaultu až po otevření souboru v GrowOS)

**Popis od autora:** Build a webinar end to end: the structure scaled to a length target, belief-chain chapter design, segment scripts in spoken register with delivery cues, a slides outline, the runsheet, and CTA choreography — from the offer, a date, a length target, the audience's temperature, and a delivery style, through the Editor gate and the queue into work/video/. Promo-kit handoffs (a registration page, launch emails, posts) are offered one at a time, only after the webinar item is approved. Triggers: "build my webinar", "webinar structure", "webinar script", "plan my webinar content", "workshop script", "masterclass outline", "slides outline for my webinar". Does not plan the promo campaign around it (campaign-plan's craft), write the registration page (landing-page-write's), write the launch emails (email-write's), write a sales-video script (vsl-write's), or render an actual slide deck — v1 ships an outline only, said honestly.
