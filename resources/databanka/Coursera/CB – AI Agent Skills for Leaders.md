# AI Agent Skills for Leaders (Coursera, Jules White)

**Použij, až:** píšeš nebo opravuješ skill (metoda RECIPE, vzorec kontextových preferencí), nebo vysvětluješ začátečnici, co je skill a proč má smysl.

Kurz Dr. Julese Whitea (Vanderbilt), 4 moduly, ~6 h, 25 videí, 5 hodnocených úkolů. Skilly pro ChatGPT, Claude a Gemini pro lidi bez programování. Nejcennější je modul 4 (RECIPE: Requests, Environment, Concrete steps, Ideal result, Presentation, Examples) a „luxusní výstupy“ (ELITE) z modulu 2. Moduly 1 a 3 jsou z velké části opakování z Anthropic Academy.
