# Paměť a učení — knižní zdroje

Doporučené knihy o technikách paměti a efektivním učení.

## Techniky paměti

- **Moonwalking with Einstein** — Joshua Foer — Od průměrného novináře po šampiona paměti; nejpřístupnější úvod do paměťových technik (method of loci, paměťový palác).
- **Unlimited Memory** — Kevin Horsley — Crash course; klíčové techniky stručně a prakticky. Dobrý start.
- **Remember It!** — (autor: paměťový šampion, zdroj: IG reel) — Vizuální step-by-step techniky z kompetitivní paměti; doplňují kurz Everest Memory Masterclass.

## Jak se učíme (kognitivní věda)

- **Make It Stick** — Brown, Roediger, McDaniel — Výzkumně podložené zásady; retrieval practice, spaced repetition, interleaving. Standard pro pedagogy.
- **How We Learn** — Benedict Carey — Jak mozek přirozeně zpracovává informace; jak strukturovat studijní čas tak, aby to fungovalo.
