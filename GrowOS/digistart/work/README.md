# Work

> This folder is where the system puts everything it makes for this business: posts,
> emails, ads, and more. Each piece is one file. You do not need to organize this
> yourself; the system keeps it tidy. This README just explains what you are looking
> at.

## How it is organized

Work is grouped by channel. A channel folder appears the first time it is used, so
this folder starts nearly empty and fills in as you go:

- `work/social/` for social posts
- `work/email/` for newsletters and emails
- `work/ads/` for ad work
- and so on, one folder per channel

## What each file is

Every file here is one deliverable with a small label at the top that tracks where
it is: being drafted, waiting for you, approved, and so on. That label is how your
review queue knows what to show you. The system manages the label; you just review
the work.

## How you interact with it

You rarely open these files by hand. Instead:

- Ask the system "what is waiting for me?" to see what needs your review.
- Open your review queue (in Obsidian, or just ask in chat) to look things over.
- Say "approved" or "change this" and the system moves it along.

Packages of related work (like a set of ads made together) get their own folder,
sometimes with a short brief file that sets the shared context.
