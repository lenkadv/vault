# Brand

> How DigiStart looks. No DigiStart site exists yet, so there was nothing to read. On 2026-10-14 Lenka said to use the look of the GNOSTIKA audit web page (the files in the vault folder `resources/digistart-balicek-stepanka/01-web-audity/`, page title "GNOSTIKA CONSULTING – personální a procesní audit"). Colors and fonts below are read from that page's own style sheet, not guessed. Whether this look is final for DigiStart is **unchecked** until Lenka confirms it on a first draft.

## Colors
Read from the audit page (`index.html`, `:root`):

- Background (warm paper): #F1ECE6, second background #E8DFD5
- Text (dark plum-black): #231A1D, muted text #5E5155
- Main accent (burgundy, buttons and links): #9B224F, darker on hover: #74183B
- Light pink for hover and soft panels: #F3D3E0
- Yellow #FFF1A8 on that page marks placeholders and review notes only. Not a brand color.

## Fonts
From the audit page's local font files (`fonty.css`, open-licence fonts):

- Headings: Archivo, bold to extra bold, narrowed
- Body text: DM Sans
- Handwritten accent: Caveat (used sparingly on that page)

**Canva brand kit „DigiStart“** (created 2026-10-30 at Lenka's request, https://www.canva.com/brand/kAHZhNXciJE): the 7 colours above (#9B224F, #231A1D, #F1ECE6, #E8DFD5, #5E5155, #74183B, #F3D3E0); text styles Název and Nadpis = **Archivo Narrow bold** (Canva has no plain Archivo, only Archivo Narrow and Archivo Black), Hlavní text = DM Sans. No logo (see below). The Canva connector cannot set a font family in a design, so text styles are applied by hand in Canva.
