# Asset index

> One line per file in this folder, saying what it is and when to use it. GrowOS
> cannot see inside a picture, so this index is the only way it knows what you
> have. A file with no line here is a file the system will never reach for.

## How to write a line

Name the file, say what is actually in it, and say when it is the right choice.
The last part is the useful bit — "the one for anything customer-facing" tells the
system more than a description of the pixels does.

```
- `logo-dark.png` — the full logo in dark ink on transparent. Use on light
  backgrounds; the default for documents and light-mode pages.
```

Note anything that limits how a file may be used: a photo you have permission for
until a certain date, a headshot you would rather not see on an ad, a screenshot
with a customer's name in the corner.
