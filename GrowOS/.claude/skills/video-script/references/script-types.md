# The four video script types

Job, pick criteria, structure skeleton, length band, and craft rules for
each of the four types this skill covers. Read the picked type's section
before Phase 3, and keep it open through Phase 4.

The length bands below are starting points, not a performance claim and
not a ceiling — a real idea that needs longer gets longer; nobody pads a
script to hit a number. All the words-per-minute math uses the same
150-170 words-per-minute band SKILL.md's Phase 4 uses for the running
timing estimate, so a script's real draft and its planned length stay
comparable throughout.

---

## youtube-longform

**Job.** A full YouTube video script, cold open through outro, built to be
watched to the end and to bring the viewer back for the next one.

**When it's the pick.** The ask is a YouTube video, a channel upload,
"make a video about X" with no shorter format named.

**Structure skeleton.**
1. Cold-open hook (0:00) — no channel-welcome.
2. Open loop — state plainly what this video actually delivers.
3. 3-5 main segments, each with its own re-hook into the next, so
   attention resets instead of decaying across the runtime.
4. CTA — placed once the value has actually landed, never before it.
5. A short outro.

**Length band.** 8-12 minutes by default (~1,200-2,000 words at
150-170 words a minute). A teach-heavy topic can run longer if the one
idea genuinely needs the room — say so rather than cutting it thin to fit
the default.

**Craft rules.**
- The hook is the single highest-leverage line in the whole script — if
  it fails, nothing after it gets watched. Give it real drafting effort,
  not the first line that comes to mind.
- Never open with a channel-welcome ("hey guys, welcome back to the
  channel"). Start on the hook; a welcome, if there is one at all, comes
  after and stays brief.
- Every visual beat gets an actual `[B-ROLL: ...]` cue, specific enough
  for an editor to shoot from — "close-up of the tool being set up," never
  "a demo."
- Read the whole thing aloud before calling it done. The ear catches
  written-not-spoken language and over-polished transitions the eye skims
  past.

## short-reel

**Job.** A single-idea, vertical-format video script built to earn its
next second, every second — for Reels, Shorts, or TikTok.

**When it's the pick.** The ask names a reel, a short, a TikTok, or "something
quick for [platform]."

**Structure skeleton.**
1. A 1-3 second hook, spoken and on-screen at the same beat.
2. The one idea, no detours.
3. A quick payoff.
4. A light CTA if any — plenty of reels need none.

**Length band.** 15-60 seconds (~40-170 words at 150-170 words a minute).
The idea sets the real length; a script padded out to fill the window
reads exactly like what it is.

**Craft rules.**
- One idea only. A second idea is a second reel, not a longer one.
- The hook is its own timing budget: 1-3 seconds is roughly 4-8 spoken
  words. Check the hook line against that count on its own, not just the
  whole script against the length target — a great 20-word hook is a
  failed hook.
- The hook has to work with the sound off — most viewers scroll muted
  first. The on-screen-text plan from Phase 5 carries the hook too, not
  only the voice.
- A `brain/stories/` entry that fits the topic gets compressed to a single
  spoken beat or skipped — this skeleton has no story slot, and forcing
  one in breaks the one-idea rule. The same belief stated in
  `methodology.md` is usually the better source at this length.
- Bold one word, maybe two, in the whole script. At reel length the
  scorer's bold-density check is strict — under ~150 words, two bolded
  spans already flag. That is the scorer agreeing with the craft, not
  fighting it: at nine words a sentence, everything bold is nothing bold.
- Write it spoken, not written. A short-reel script is closer to talking
  out loud than to reading a caption.
- No channel-welcome open here either — the first frame is the hook,
  always.

## talking-head

**Job.** One continuous direct-to-camera piece — a single take, a real
conversation with the viewer, not a produced multi-segment video.

**When it's the pick.** The ask is "record me talking about X," a
to-camera piece, no b-roll-heavy production implied.

**Structure skeleton.**
1. A natural opening — this can ease in rather than cold-open, since it's
   one continuous take.
2. The point, made plainly.
3. Natural segments — a shift in the thought, not a scripted re-hook.
4. A natural close.

**Length band.** 2-6 minutes by default (~300-1,000 words at 150-170
words a minute). A real conversation runs as long as the point actually
takes.

**Craft rules.**
- Write it the way this person actually talks, not the way a script
  reads. Read `brain/samples/` for spoken content if any exists — this
  type needs it most.
- Segments are natural shifts in thought, not scripted re-hooks. One take
  means the transitions have to sound like thinking out loud, not section
  breaks.
- Use fewer production cues than the other types. `[PAUSE]` and
  `[ENERGY: ...]` sparingly, not a bracket a line — this is close to
  unscripted.

## ugc-style

**Job.** Native, unpolished-on-purpose content that reads like a real
person talking, not a produced ad.

**When it's the pick.** The ask wants something that doesn't look "made" —
native content for organic social, a testimonial-style or day-in-the-life
piece.

**Structure skeleton.**
1. An immediate, plain opening — no hook engineering; the unpolished feel
   IS the hook.
2. The real point or story.
3. An honest, low-pressure close.

**Length band.** 15-45 seconds by default (~40-130 words at 150-170 words
a minute). A longer piece is still a talking-head or a short-reel
underneath — call it that instead.

**Craft rules.**
- Unpolished is a choice, not an excuse. Every word is still checked
  against the brain and never fabricated because "it's just UGC."
- This is organic content, never an ad. An ad-round asset that happens to
  look native is `ads-meta-create`'s job, not this skill's — asked for
  "an ad that looks like UGC," route there instead of drafting it here.
- Write it the way a real customer or the owner would actually say it,
  not the way a marketer would write dialogue for them.
