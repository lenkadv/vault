# library/ — co tady je

Co si tadylenka nashromáždila a naučila (v GrowOS 2.0 mimo `brain/`).

- **`content-bank/`** — banka myšlenek a zdrojů, jeden soubor = jeden námět. Schéma: `content-bank/_SCHEMA.md`.
- **`Content Bank.base`** — filtrovaný pohled na content-bank (pohledy: Tři rubriky / per-rubrika / Jiné / Použité / Retired).
- **`swipe-content.md`** — formátové vzory a mechaniky cizího obsahu s poznámkou, proč fungují.
- **`process/`** — starší publikační postupy (0.1). Živý postup je v `brain/methodology.md`.
- **`youtube/`, `youtube-planning/`** — YT research, neodstartovaný plán.
