# inspiration/ — účel

Čisté vizuální/náladové reference bez analýzy — obrázky, screenshoty, momenty, které něco vystihují, ale nejsou (ještě) rozebrané na mechaniku.

**Liší se od `swipe-files/`:** swipe-files/ jsou konkrétní mechaniky a formáty cizího obsahu s poznámkou, proč fungují (rozebrané, použitelné jako vzor). inspiration/ je nezpracovaný materiál — nálada, styl, vizuál — bez rozboru.

Když se něco z inspiration/ rozebere na konkrétní mechaniku, patří to přesunout do `swipe-files/`.
