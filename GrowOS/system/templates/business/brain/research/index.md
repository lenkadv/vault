# Research index

> One line per research file, newest first. This is the folder's own index —
> what a session reads to know what has been researched without opening every
> dated file. `brain-capture` adds a line here every time it files research; if you
> drop a file in by hand, add its line too. The main index in
> `memory/MEMORY.md` points at THIS file and never lists individual findings.

Line shape — write real entries as wikilinks, so the Doctor notices if the
file ever goes missing:

```
- [[2026-07-02-pricing-competitors]] — what the three closest competitors
  charge; checked against their live pages that day.
```
