# Samples index

> One line per sample, newest first. This is the folder's own index — the one
> file a session reads to know what is here without opening a hundred samples.
> `brain-capture` adds a line here every time it files a sample; if you add a file by
> hand, add its line too. The main index in `memory/MEMORY.md` points at THIS
> file and never lists individual samples.

Line shape — write real entries as wikilinks, so the Doctor notices if the
file ever goes missing:

```
- [[2026-07-14-launch-email]] — the June launch email; the owner's warmest
  voice, good for openings.
```
