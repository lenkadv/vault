## Template usage notes (for the skill — not part of the output)

- One entry per unblock session. Append to the bottom of the log file.
- Keep the task name short (3-8 words). The user will scroll through these later — long task names make scanning painful.
- "Outcome" stays as `Pending` until the user comes back and reports — see Step 6 of the main SKILL.md. Replace it with the reported outcome when they do.
- Possible Outcome values:
  - `Started — got into the work.`
  - `Partial — made some progress.`
  - `Still stuck.`
  - `Dropped.`
  - `Completed.`
- Use 24h time in the header for sorting consistency.
- The horizontal rule (`---`) separates entries visually. Keep it.
