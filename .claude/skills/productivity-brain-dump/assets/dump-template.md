## Template usage notes (for the skill — not part of the output)

- Replace ALL bracketed placeholders with real content.
- **Omit entire sections** when the bucket is empty. Don't leave empty headers — they make the dump look incomplete when it isn't.
- The optional one-sentence framing at the top only fires if there's an obvious theme. Most dumps are mixed; skip it.
- For Tasks, use the enriched form (verb-led, 🔥 prefix for urgent, [Goal Area] suffix where matched). Tasks in the dump file should look identical to the lines that get appended to next-actions.md.
- For Notes capturing emotional content, preserve the user's original phrasing where possible. Don't paraphrase a worry into a tidy sentence.
- Use 24h time everywhere for consistency with the rest of the pack.
