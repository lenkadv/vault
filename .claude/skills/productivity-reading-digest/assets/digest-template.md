## Template usage notes (for the skill — not part of the output)

- Replace ALL bracketed placeholders.
- **Omit sections** that don't apply (no items beyond cap, no goals file, no action items, etc.). Empty headers make the digest feel hollow.
- The "What stood out" section at the top is what the user will look at first. Spend the inference effort there. 2-3 lines, specific, name the pieces.
- Order articles by relevance/strength, not just by source priority. The user's read order is more important than data orderliness.
- For each article, the link to the original goes at the BOTTOM of the entry, not inline in the title. The user reads the summary first; if it's compelling, they then click through.
- Read-time estimates are useful but don't pretend to be precise. Round to 5 min / 10 min / 15+ min.
- For newsletter-as-article entries, the "Link" line can be "(Email — see Gmail for full content)" if there's no public URL.
- Use 24h time everywhere.
