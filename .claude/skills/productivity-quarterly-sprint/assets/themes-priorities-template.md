## Template usage notes (for the skill — not part of the output)

- Replace ALL bracketed placeholders.
- **Overwrite** this file each quarter. Don't append. Each quarter starts fresh.
- Themes count: 1-3 maximum. Push back hard against 4+. The whole point is focus.
- Priorities per theme: 3-5. Less than 3 might mean the theme isn't fully developed; more than 5 dilutes the priorities into a to-do list.
- Metrics are optional. Don't manufacture metrics for priorities that don't have natural ones. "Have more meaningful conversations" doesn't need a metric.
- Standing time blocks are concrete weekly cadences. Specific day + specific time. Vague time blocks ("morning sometime") don't make it onto the calendar.
- This file is what makes the quarterly intent show up in daily and weekly work. Without it, themes evaporate by week 3.
