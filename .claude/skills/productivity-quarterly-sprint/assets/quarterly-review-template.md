## Template usage notes (for the skill — not part of the output)

- Replace ALL bracketed placeholders.
- **Omit sections** that don't apply (no calendar audits run → drop the Calendar shape section).
- The reflection answers should be verbatim. Don't paraphrase. This is the user's quarter in their own voice.
- The themes/priorities section is the most-referenced output. Format consistently across quarters so the user can compare.
- The "operationalization" section is where most quarterly reviews fail — they reflect well, plan well, but never act. Make this section concrete. Time blocks have specific weekday+time. Cadences have specific run-times.
- For Decision Journal reviews due: pull from the decision journal frontmatter `review_date` field. Filter to dates in the upcoming quarter.
- Cross-references to previous quarter's review help create continuity. Always include if a previous review exists.
- Use 24h time everywhere.
